# NPC ghost appearance: audit and private state candidate

The original production NPC-create packet carries ghost in flag 0x01. Godot applies a front-surface depth pass plus translucent original textures and a subtle cool-white rim. Monster opacity is 0.5; Catacombs race-figure opacity is 0.9, retaining skin/dye color and hair coverage. Original equipment is ghosted too. This is distinct from local-player stealth and must not reuse its gray/0.45 presentation.

The predecessor adapter retained realm/flying/name/targeting but dropped the ghost rendering contract. The installed adapter now publishes a separate `npc_visual` object from NPC-create only. NPC movement flags encode zone information and cannot replace create flags. Original NPC TORCH is separately normalized to database bit0x40; the original NPC view does not create a personal-light source from it, so the audit does not authorize adding NPC or building illumination.

`verify_npc_visual_flags.py` extracts the original Godot normalization block unchanged and compares all 256 first-byte combinations against representative second-byte states. The 1,815 candidate checks also cover malformed bytes, unrelated movement/player packets, reused identities, missing create data and copied-state isolation. Eight adapter checks exercise actual create/move/model/equipment/remove/region handling. These metadata checks precede the native and installed acceptance recorded below.

Private materials preserve source uniforms, textures and the original color/normal/specular/roughness graph. The render harness checks nonblank figures against a separate background and exact restoration; it hashes protected assets and the installed binary/catalogue. Initial diagnostic lighting and a moved backdrop produced misleading dark cuts, so neither fixture was accepted. The corrected fixture uses one common point light and recreates the backdrop for each viewpoint. Both models now pass front, back and two side comparisons: eight ordinary/ghost/restored sets, with zero restoration error. Filtered captures remove the inner eye/cloth/boot faces visible in the unfiltered diagnostic. This is static sample acceptance, not gameplay or full NPC model coverage.

The candidate actor-local controller now passes 48 native lifecycle checks, including MID uniforms, shared-asset isolation, equipment insertion/hiding, unknown/off state, replacement outfits, actor changes/removal and source draw-distance/bounds inheritance. Repeated frames reuse the same material state; a new snapshot refreshes equipment uniforms, while leader-pose depth follows animation. Another 486 native movement/pose/combat/torch regressions pass. Its native render fixture captures 16 frames across two original idle poses per model, with nonzero pose changes and zero restoration error. The ordinary/ghost/reference materials and installed binary remain unchanged.

An isolated real-server run passes 28 checks using two ordinary players and three disposable NPC records (normal/ghost Zombie and ghost Celt). Both peers receive the original create-bit metadata. Private data and libraries are restored after normal client/server shutdown; the played installation is unchanged. The normal native NPC coordinator additionally passes 21 checks replaying those actual server rows through entity creation, including same-identity replacements, missing/invalid metadata, menu/removal/stale cleanup and effect-only fallback. Strict JSON booleans prevent Unreal's permissive string-to-boolean conversion from manufacturing ghost state. This replay is not a live native-server session.

The private catalogue preserves all 76 predecessor entries and adds the original Zombie/Celt samples. Original monsters.json classifies race figures and effect-only bodies; 67 of 78 rows have source classification and unknown custom rows retain ordinary appearance. A read-only asset-registry survey covers 50 unique exported body meshes and 3,006 original body/equipment material paths, including engine glTF defaults. The separate full ghost library maps all 3,006; source asset hashes, graph properties, uniforms and static switches are protected. The full library passes the 48+486 native checks, 21 coordinator checks and the 16-frame sample comparison. It does not supply unexported world models.

The bounded package is now installed with an exact 3,049-file inventory and reversible predecessor backups. Fifty-eight installation-chain simulations reject damaged code, catalogues, asset entries and receipt metadata before deployment. The installed ordinary client repeats all 534 native checks, 21 coordinator checks and 16 animation captures with exact material restoration. The central predecessor chain passes after installation; played data, server rules and map geometry are unchanged. Owner gameplay acceptance remains deferred. Effect-only bodies and missing world-model imports are explicit next work, not completed by this delivery.
