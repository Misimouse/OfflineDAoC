# Original realm-war overview

The bridge previously decoded realm-war packets in Godot but did not expose their state or original window in UE5. This package adds a bounded read-only contract, original artwork and native window. Type `/realmwar` during play. Albion, Midgard and Hibernia tabs and Update request the original server pages; Escape or the painted cross closes the window. Position is saved per character.

Only received ownership is displayed as known. Static artwork does not establish ownership. Battle information remains explicitly unavailable until an actual battle packet arrives. Original DOL public keep rows were exercised in a backed-up disposable server with an ordinary player. No played database, server rules, world geometry or teleport capability changes.

The original atlases depict classic frontiers; the pinned DOL public database includes New Frontiers. Keep ownership uses stable keep identities. Battle markers require an exact tile-zone match and cannot place NF coordinates on classic tiles. This delivery does not implement the frontier world, siege controls or a complete RvR acceptance.

Also fixes world-click passthrough while the quantity chooser is open. The chooser remains the original Shift+drag interaction, validated against empty backpack and current personal/account vault destinations.

Acceptance: 31 state checks, 13 ordinary-player server checks with original DOL keep identities, 22 native realm-war checks including actual Slate delegates and captured atlases, 20 native quantity checks, 25 vault state / 87 native vault checks, and 53 window-recovery checks. Native verification uses an isolated UE host; all source/build/evidence digests must match the guarded install plan. Installation simulates the complete predecessor chain, rejects damaged receipts, backs up every replaced file, checks the normal ports are unused and rolls back on failure. A second native run exercises the installed client.

Owner review remains pending: open `/realmwar`, switch all three realms, press Update, move and close the window, reopen it, and verify inventory quantity selection. An empty Connacht server may have no frontier ownership data; the window must report missing data rather than invent owners or battles. Existing launcher and account remain in use.
