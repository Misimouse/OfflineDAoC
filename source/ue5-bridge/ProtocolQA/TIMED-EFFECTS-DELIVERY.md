# Original timed spell effects

This package verifies the installed effect-strip implementation without replacing runtime files.

A disposable ordinary Bard uses the original Hymn of Body Guarding, including its original five-second effect, pulses and recovery time. Thirteen real checks cover the received spell, icon, polarity, real deadline, renewal without duplicate icons, fresh identity after renewal, refusal of stale descriptions, server-confirmed removal after stopping the chant, disappearance of the timer and repeated activation/stop. The test waits for the actual recovery timer rather than weakening the cooldown gate. The complete marked private database, temporary configurations and private server libraries are restored on exit. The played database is never opened for writes.

Twenty-two state checks cover timed and permanent effects, countdown without catalog rebuild, overdue timers clamped to zero without inventing effect removal, descriptions, expiry, replacement at the same server index, stale identities and refusal to turn active effects into usable quickbar skills. Sixty-eight installed native interface checks include actual effect tiles, description dispatch, no skill drag and pointer behavior when the strip is empty.

No generic manual buff cancellation is invented. Concentration cancellation remains its separately verified original command. Visual spell bursts, every debuff and every class effect are outside this bounded lifecycle test.

Owner review: cast a maintained resistance chant, watch one icon refresh, stop the chant after its recovery finishes, and check the icon disappears. Right-click an effect for its original description. Permanent effects should have no countdown. Owner gameplay acceptance remains pending.
