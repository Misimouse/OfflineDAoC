# Original NPC effect bodies and attachments

The original client defines 45 monster models with attached effects; 33 have no race/body mesh because the effect is the creature. The current native catalogue contains two such cases, Wisp 966 and Buzzing Flies 2020, both marked hidden. Native creation therefore returns before an actor, effect, name or selectable body can exist.

Original `npc.gd::_attach_effects` attaches to a named skeleton bone when available, otherwise to the NPC origin. AutoScale multiplies geometry by spawn size/50 and original model scale. Effect-only float height is independent of that geometry scale; `float_m` converts original world units by 0.025 metres. Wisp uses a fixed 50 units, or 1.25 metres, and source effect range 60 metres. Flies use 62.5 metres. No inferred point light is authorized by these resources.

Private extraction reuses only the existing spell extractor's function definitions, without executing its top-level exporter. It retains original geometry, tint/opacity animation, node animation, particle timing/modifiers, textures and billboard metadata. The 44 unique resources use 36 textures: 29 existing native spell texture assets can be reused, leaving seven private imports. The original sources and installed catalogue/binary are hash-guarded. Neither current effect has source warnings or inherited parent transforms; 14 other resources have original conversion warnings and must not be declared visually complete from successful extraction.

The native procedural spell/weapon renderer already supplies bounded mesh sections and particle emitters, texture materials and lifetime cleanup. Its mesh path does not yet orient original `billboard: face` cards to the camera. A Wisp needs that card plus its particles; a horizontal unrotated card is not an acceptable body. Persistent NPC effects must have separate budgets and cannot consume the transient spell-effect allowance. Reuse the renderer instead of inventing replacement meshes.

Selection and name placement need effect-body bounds. Ordinary body picking intentionally excludes particles/weapons; explicitly marked effect bodies need their own conservative drawn bounds. Original particle visibility boxes have a minimum four-metre radius for culling and must not become an eight-metre clickable Wisp. Respect targetable/name flags and original range, clean up on removal, model change, stale snapshot and lobby, and preserve ordinary NPCs and spell/weapon effects.

The private candidate now supplies 31 native NPC checks, 30 existing spell checks and 534 ghost/light/pose/combat/movement checks (595 total). Thirty-two rendered captures cover both current effect-only models, four camera views and two original animation times. Actual draw bounds supply picking and name placement; source visibility AABBs do not. Original particle size is a radius, and bounded emitters sample the full original particle age distribution. A visible warm-up capture is required before comparing newly created procedural scene proxies.
