# Quest offers and rewards in the UE5 client

The installed client displays original server offers and rewards with the classic dialog art, font and item icons. Accept and Decline respond to the current offer. Finish requires the exact number of choices shown by the server. Not Yet dismisses the reward and preserves the quest.

A response is bound to the current nearby NPC and dialog. Stale clicks and repeat submissions are ignored. The server controls the journal, items and money. The client waits for a journal update and never retries a reward automatically.

The codec passed 265 checks, the dialog state passed 49 and the rendered Unreal controls passed 19. The private ordinary-player run passed 14 original protocol checks and nine gateway checks. The nine gateway checks passed again with the installed files. The fixture used an isolated quest and original DOL handlers. The delivery includes the decoder, gateway and UE5 window.
