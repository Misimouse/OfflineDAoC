# Original keyboard turning: bounded native delivery

The original modern-mode player turns at PI radians/second (180 degrees/second). With the right mouse held its turn keys strafe; otherwise they rotate the character, including at rest. Left mouse hold keeps the camera independent. Manual turn cancels follow/stick, whereas face remains active and allows the original angular offset/right-mouse strafe behavior. Native Left/Right arrow defaults are editable in both key slots; accepted A/D strafing, mouse orbit, sprint and weapon actions remain intact. Existing explicit saved bindings take precedence over newly introduced defaults. This makes75 editable native actions; it is an input inventory, not a completion percentage.

The native helper receives existing availability gates, converts the original yaw sign to Unreal and preserves the180-degree/second rate at15/30/60/144 FPS. Opposite keys cancel, invalid frame times cannot apply a turn and a stalled frame is bounded to one second. No changes to speed, collision, database, server authorization or WORK assets are needed. Idle yaw uses the existing movement packet; an actual native dispatch check validates its forward vector and zero speed.

The private native acceptance covers330 key/settings/input checks,108 turn and movement/backward-cadence checks across13 models,35 tracking checks,136 original UI/legacy death-release checks and23 original positive-one-HP/rounded-zero-percent checks. Actual input includes idle rotation, left-button independence, right-button strafe, seated/dead/chat/options/riding/missing-session blocks, follow/stick cancellation and face preservation. Focus gating is the existing common input gate; the offscreen actual-input fixture explicitly supplies focus. It is not a live mounted-route or unfocused-window owner test.

The first expanded tracking fixture incorrectly reused a smaller request sequence after stick; the existing monotonic guard correctly rejected it. The fixture sequence was corrected before rerunning the final compilation. No gameplay guard was relaxed. The ordinary-server weapon/sprint predecessor remains independently sealed and verified; this native-only package does not claim a new live server run.

Delivery is limited to two native binaries and six source/helper files. The full installed predecessor chain, exact fingerprints, backup and reversal are checked. All632 checks pass on the candidate and repeat against the installed client;34 delivery simulations and guarded rollback preview pass. Owner gameplay review remains separate. Full RPG/FPS/MMO presets, character-specific key maps, classic mode and unrelated controls are not included.
