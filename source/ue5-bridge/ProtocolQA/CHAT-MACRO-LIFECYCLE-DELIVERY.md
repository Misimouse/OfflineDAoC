# Original chat and macro lifecycle

This package verifies the installed implementation without replacing runtime files.

Fifteen real checks use two ordinary disposable accounts and a real server group. They cover literal group/private/guild text, original channel classification, rejecting multiline and overlong commands, macro creation without execution, quickbar dispatch of client `/loc`, server `/gloc` and local `/qbar`, exact command descriptions, stale identity refusal, per-character saved definitions/pages, unchanged inventory/points, and normal group departure. The marked private database, temporary server libraries/configurations and both characters' private shortcut files are restored on exit. No message is sent to real people or external services.

The existing chat and macro suites pass 27 and 25 checks. They include bounded history, original channel types, session reset, NPC bubbles/region notices, immutable snapshots, macro syntax, canonical command resolution, character isolation, persistence, legacy shortcut migration, and preserving occupied slots. Eighty installed native checks exercise the existing interface, including macro drag, shortcut identity and literal command inspection.

The normal native installation remains the compass delivery. Chat-window presentation and a general redesign are outside this package. Owner gameplay acceptance remains pending.

Owner review: create `/macro LOC /loc`, use its quickbar icon, inspect it with the right mouse button, move it to another slot/page and re-enter the character. Test group, private and guild chat with another test character if convenient. Creating the macro must not execute it.
