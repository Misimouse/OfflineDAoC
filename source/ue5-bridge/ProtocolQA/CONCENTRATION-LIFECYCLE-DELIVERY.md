# Existing original concentration lifecycle

This verification package exercises the existing concentration window, original Status pool and DOL RemoveConcentration packet. It does not replace runtime code or create an alternative buff system.

Fourteen real checks use two ordinary disposable accounts. The caster removes a restored private effect, casts the original Strength of the Tree and Dexterity of the Wolf spells on itself, sees the original owner, cost and icon, and receives the corresponding deduction from its original concentration pool. Another account cannot cancel those effects. A token from the prior list cannot cancel the current list. Cancelling one selected buff preserves the other, removes its real effect and refunds only its own cost; cancelling the last buff restores the server pool. A removed token cannot be reused.

The private database, configuration and server libraries are restored after normal shutdown. The played database is untouched. 26 original state checks cover uncertain and reordered lists, identity generations, malformed indices, pending requests and safe handling of missing confirmations. 82 installed native checks include ordinary right-click versus Shift/right-click, original spell-list index/token, a second page without renumbering, and duplicate cancellation prevention.

An earlier headless attempt to cast on the second player was correctly refused for missing native line-of-sight evidence. It was not bypassed. This package therefore certifies self buffs and foreign-cancellation refusal; it does not certify cross-player casting geometry or general timed/debuff cancellation. Those limits remain explicit.

Owner review: on a caster, cast two concentration buffs on yourself. In the existing concentration window, Shift/right-click one entry; check that only that buff disappears and the other remains. Right-click alone must not cancel it. Pool and icons depend on actual server replies.
