# Original ordinary-player training

This package verifies the installed implementation without replacing runtime files or changing training rules.

Fourteen real checks use ordinary disposable accounts and the existing original `allow_train_anywhere=True` configuration. A level-50 Druid trains Nurture from 11 to 12 and then 13. The server deducts exactly 12 and 13 points, respectively. Strength of the Grove is visible as an original level-13 preview while unlearned, stays unusable at 12, then enters the usable server skill catalog after training to 13. The test also covers another character's refusal, stale and reused confirmations, agreement between trainer and character points, unchanged inventory, and the specialization saved by normal logout. The entire marked private database and temporary server/configuration files are restored.

Twenty-eight existing state checks cover original packet indices/next level, previews, costs, availability, pending requests, timeouts, malformed indices and session changes. Eighty-two installed native checks include original trainer art, selection, descriptions, scrolling, exact training identity and retained position.

No claim is made that every specialization, promotion, class or realm ability was tested by this bounded package. Owner gameplay acceptance remains pending.
